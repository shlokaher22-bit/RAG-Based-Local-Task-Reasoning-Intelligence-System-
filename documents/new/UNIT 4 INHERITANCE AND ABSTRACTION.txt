SECTION 1
INHERITANCE

- 4 — What is Inheritance?
Inheritance allows a class to acquire properties and behaviour from another class.
Syntax
class Child extends Parent {
}
Example
Vehicle
   |
   +---- Car
   |
   +---- Bike
Benefit
Code reuse + specialization

- 5 — Basic Inheritance
class Vehicle {
 
	void start() {
 
    	System.out.println(
        	"Vehicle starts"
    	);
	}
}
 
class Car extends Vehicle {
 
	void openBoot() {
 
    	System.out.println(
        	"Boot opened"
    	);
	}
}

- 6 — Using Inheritance
public class Main {
 
	public static void main(String[] args) {
 
    	Car c = new Car();
 
    	c.start();
 
    	c.openBoot();
	}
}
Output
Vehicle starts
Boot opened

SECTION 2
METHOD OVERRIDING

- 7 — Method Overriding
When a subclass provides a new implementation of an inherited method, it is called method overriding.
class Vehicle {
 
	void start() {
    	System.out.println(
        	"Generic start"
    	);
	}
}
 
class Car extends Vehicle {
 
	@Override
	void start() {
 
    	System.out.println(
        	"Car starts"
    	);
	}
}

- 8 — Why @Override?
@Override tells the compiler:
This method is intended to override a superclass method.
Benefits
Detects spelling errors
Detects incorrect method signatures
Improves readability
Makes intention explicit

SECTION 3
POLYMORPHISM

- 9 — What is Polymorphism?
Polymorphism means:
One interface/reference can represent different forms of behaviour.
Example
Vehicle v;
 
v = new Car();
v.start();
 
v = new Bike();
v.start();
Same reference type.
Different runtime behaviour.

- 10 — Runtime Polymorphism
class Employee {
 
	double salary() {
    	return 0;
	}
}
 
class FullTime extends Employee {
 
	@Override
	double salary() {
    	return 60000;
	}
}
 
class Intern extends Employee {
 
	@Override
	double salary() {
    	return 15000;
	}
}

- 11 — Polymorphic Collection
Employee[] team = {
 
	new FullTime(),
	new Intern()
};
 
for(Employee e : team) {
 
	System.out.println(
    	e.salary()
	);
}
Key Idea
The method executed depends on the actual object at runtime.

SECTION 4
SUPER KEYWORD

- 12 — super Keyword
super refers to the immediate superclass.
Uses
Call superclass constructor
Call superclass method
Access superclass field where permitted

- 13 — Superclass Constructor
class Person {
 
    String name;
 
	Person(String name) {
 
    	this.name = name;
	}
}
 
class Student extends Person {
 
	int rollNo;
 
	Student(String name, int rollNo) {
 
    	super(name);
 
    	this.rollNo = rollNo;
	}
}
Important
super(...) must be the first statement in a constructor.

- 14 — Calling Superclass Method
class Person {
 
	void display() {
 
    	System.out.println(
        	"Person information"
    	);
	}
}
 
class Student extends Person {
 
	@Override
	void display() {
 
    	super.display();
 
    	System.out.println(
        	"Student information"
    	);
	}
}

SECTION 5
ABSTRACTION

- 17 — What is Abstraction?
Abstraction means:
Showing essential features while hiding implementation details.
Example
When using an ATM:
You see:
Withdraw
Deposit
Balance
You do not see the internal banking implementation.

- 18 — Abstract Class
An abstract class:
Cannot be instantiated directly.
May contain abstract methods.
May contain concrete methods.
May contain constructors.
Can contain variables and methods.

- 19 — Abstract Class Example
abstract class Shape {
 
	abstract double area();
 
	void printType() {
 
    	System.out.println(
        	"This is a shape"
    	);
	}
}

- 20 — Concrete Subclass
class Circle extends Shape {
 
	private double radius;
 
	Circle(double radius) {
 
    	this.radius = radius;
	}
 
	@Override
	double area() {
 
    	return Math.PI *
               radius *
               radius;
	}
}

SECTION 6
PROTECTED

- 21 — protected Access
protected provides:
Access within the same package
Access to subclasses under Java's protected rules
Example
class Account {
 
	protected double balance;
}
 
class SavingsAccount
    	extends Account {
 
	void addInterest(double rate) {
 
    	balance +=
        	balance * rate;
	}
}
Design Tip
Use protected carefully; prefer stronger encapsulation where possible.

SECTION 7
FINAL KEYWORD

- 22 — final Keyword
final can be applied to:
Variable
Cannot be reassigned.
Method
Cannot be overridden.
Class
Cannot be extended.

- 23 — final Method
class Audit {
 
	final void log() {
 
    	System.out.println(
        	"Audit completed"
    	);
	}
}
A subclass cannot override:
void log()

- 24 — final Class
final class SecurityUtility {
 
	static void authenticate() {
 
    	System.out.println(
        	"Authentication"
    	);
	}
}
Cannot write:
class Child
	extends SecurityUtility {
}
